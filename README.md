## Como rodar o projeto
```
$ # clone o repositório
$ git clone https://github.com/vMatheusCouto/prova-dsw.git

$ # inicialize a venv e ative-a
$ python .m venv venv
$ .venv\Scripts\activate

$ # instale as dependências
$ pip install -r requirements.txt

$ rode o projeto
$ python manage.py runserver
```
